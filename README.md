# Brain Tumor Detection

A deep learning-based web application for brain tumor detection from MRI images.

## Technologies Used

- Python
- TensorFlow / Keras
- Flask
- HTML
- Jupyter Notebook

## Project Structure

- `main.py` - Flask backend
- `templates/index.html` - Web interface
- `brain_tumor_detection.ipynb` - Model development and training

## Note

The trained `model.h5` file is not included in this repository because it exceeds GitHub's 100 MB individual file limit.
